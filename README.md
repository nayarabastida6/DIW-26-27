## Sobre este repositorio

Este repositorio está dedicado al módulo **Desarrollo de Interfaces Web (DIW)**, correspondiente al segundo curso del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

En él se irán publicando los diferentes trabajos propuestos durante el curso académico 2026-2027.



## 📂 Estructura del repositorio

El repositorio estará organizado en carpetas, siguiendo la estructura de los ejercicios y prácticas realizados durante la asignatura.

Cada carpeta contendrá los archivos y recursos necesarios para cada trabajo, incluyendo código HTML, CSS, imágenes y otros elementos utilizados en su desarrollo.

### Ejemplo de organización

<i>La carpeta `trastienda-ud4` corresponde al primer trabajo subido a este repositorio.</i>
```text
DIW-26-27/
└── trastienda-ud4/
    ├── css/
    ├── img/
    ├── carrito.html
    └── index.html
```



## 🎯 Objetivo

El objetivo de este repositorio es mantener organizados todos los trabajos realizados durante la asignatura, facilitando su seguimiento a lo largo del curso.
